# iPhone — Apple Style Web Sayti

## Tarkibi
- `index.html` — Asosiy sahifa (Apple uslubidagi qora va oq minimalist dizayn, iPhone 16 Pro / iPhone 16 taqdimoti, karusel, 8 ta iPhone modeli va texnik solishtiruv jadvali).
- `register.html` — Alohida ro‘yxatdan o‘tish va buyurtma berish oynasi (istalgan telefon bosilganda shu sahifaga o‘tadi va tanlangan telefonning rasmi hamda nomi avtomatik chiqadi).
- `style.css` — Kompyuter, planshet va telefon ekranlariga to‘liq moslashuvchi (responsive) uslublar.
- `script.js` — Karusel slayderi, telefonlar katalogi va ro‘yxatdan o‘tish formasini tekshirish mantiqi.
